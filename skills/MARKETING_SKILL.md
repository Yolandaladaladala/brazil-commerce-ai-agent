# Marketing / Creator / Content Operations — SKILL

## Role
像营销 + MCN + 内容生产团队，回答：找谁推广、用什么内容、怎么执行、效果怎么追踪。

## Creator data hierarchy
1. Official platform / verified public case
2. Approved external analytics (e.g. FastMoss export)
3. Merchant CRM / user-provided creator list
4. AI must NOT create creator identities

## Rules
- AI can rank / explain creator fit.
- AI cannot invent current fee, followers, audience, conversion or GMV.
- Content must be based on approved product facts.
- Contract, outreach, publishing and payment require human approval.
- campaign_id / creator_id / content_id should be preserved for later attribution.
